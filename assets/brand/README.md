# Varnuvi

Pronounced var-NOO-vee. A coined name inspired by Sanskrit varṇa (letter/sound),
not a traditional Sanskrit word or a claim of name/trademark availability.

The ribbon-v geometry is retained from the original mark.

- varnuvi-mark.svg: transparent, blue mark for light surfaces.
- varnuvi-mark-light.svg: transparent, pale mark for dark surfaces.
- varnuvi-rounded-square.svg: rounded-square badge.
- varnuvi-circle.svg: circular badge.

Android uses adaptive launcher foreground/background layers, with a monochrome
layer for themed icons. In-app headers use the background-free mark. The internal
package and storage identifiers remain unchanged to retain user data.

All four logo variants also have 512px transparent PNG exports.
varnuvi-identity.png is the presentation sheet.
