# App screenshots

Captured from Varnuvi's ARM64 release preview on a Pixel 9 in dark appearance.
The README keeps these in a closed real-screenshots dropdown, renders them at
220 px wide, and links to the full-resolution PNGs. The default five-panel showcase is AI-created artwork in `../showcase/`,
with small visible spaces between panels.
They are documentation assets and are not included in the application bundle.

- `speak-dark.png`: empty editable output, no recorded or personal transcript.
- `apps-dark.png`: app search filtered to Keep; friendly names only.
- `ai-dark.png`: connected settings after a successful model test, with Use AI
  off and Retest connection. The credential field contains no key. Key removal
  is available through Connection options.

Refresh screenshots when the interface changes. Inspect every capture for
credentials, private transcripts, notifications containing personal text, and
unrelated app content before committing. Keep source images unaltered; control
README display size in HTML.
