# Changelog

## 0.1.0 — first self-hosted release

- Android dictation with a draggable overlay microphone and explicit copy/paste.
- Continuous 30-second uploads, up to 30 minutes per recording.
- Editable results, local History, and light/dark/system appearance.
- User-configurable speech endpoint and Keystore-encrypted server token.
- No shared server address, credentials, accessibility service, or app tracking.
- Optional AI writing with the user's own OpenRouter connection.
- Standalone authenticated faster-whisper API and PC/EC2 deployment guide.

This release uses Android base build 7 so existing release-signed previews can
upgrade without decreasing their version code.
